# Publishing spdtst

This file is for maintainers. It is deliberately kept out of the user-facing README.

## PyPI

The repository is ready to build a Python source distribution and wheel. The GitHub Actions workflow in `.github/workflows/publish-pypi.yml` publishes both when a GitHub Release is published.

One-time setup before the first release:

1. Create the `spdtst` project on [PyPI](https://pypi.org/).
2. In its publishing settings, configure Trusted Publishing for the `brunozapico/spdtst` repository, the `publish-pypi.yml` workflow, and the `pypi` environment.
3. Create and publish a GitHub Release whose tag matches the version in `pyproject.toml`, for example `v0.1.0`.

No API token needs to be stored in the repository when Trusted Publishing is configured. After that release completes, users can install the public package with:

```bash
pipx install spdtst
```

## Homebrew

Homebrew formulas belong in a dedicated tap repository, typically `brunozapico/homebrew-tap`, rather than this source repository. The template at `packaging/homebrew/spdtst.rb.tmpl` is ready to copy there after a GitHub Release exists.

For each release:

1. Replace `VERSION` with the release version, without `v`.
2. Download the GitHub release source tarball and replace its SHA-256 placeholder.
3. Replace the `truststore` resource URL and SHA-256 with the values generated by `brew create --python --set-name spdtst <release-tarball-url>`.
4. Save the final formula as `Formula/spdtst.rb` in the tap repository and push it.

Users can then install it with:

```bash
brew tap brunozapico/tap
brew install spdtst
```

The formula is intentionally a template: publishing it with placeholder checksums would produce an unsafe and unusable installation.
